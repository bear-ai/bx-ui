# bx-ui 0.4.7

## 修复

- 修复高级入站配置编辑后丢失的问题，保留协议、传输、TLS 和嗅探等配置中的未展示字段。
- 增加 XHTTP 高级 JSON 编辑；非法 JSON 会阻止保存，避免悄悄覆盖有效配置。
- 新增入站保存及 Xray 重启预检。网页新增/编辑入站须在新配置启动成功后才提交数据库；预检或启动立即失败会撤销本次保存，启动替换失败时尝试恢复上一份运行配置，页面直接提示错误。
- 预检和正式运行统一隔离外部配置目录环境变量，避免隐式加载未经检查的配置；自定义配置请放入面板管理的配置模板。
- 修复新增入站接口可通过提交已有 ID 覆盖记录的问题。
- 修复 TUN 默认部署的权限检查与启用流程，预检不会创建或修改运行中的 TUN 接口。
- 增加独立 Linux TUN 实际运行测试，并将验证设为发行包构建门禁。

## 升级说明

可在“系统状态”检查并在线更新面板。现有账号、入站、证书及 Xray 核心不会被面板在线更新替换。完整安装包的 Xray 兼容基线仍为 v26.3.27。

启动保护检查启动时的失败，不代替持续连通性监测。离线迁移只预检和导入数据，不启动 Xray。

普通入站无需额外操作。TUN 首次启用需要 Linux root 管理员执行一次：

```sh
/usr/local/x-ui/x-ui tun enable
```

命令会重启面板，并为面板及其 Xray 子进程增加 `CAP_NET_ADMIN` 和 TUN 设备访问权限；仍以非 root 服务账户运行。在线更新不会自动放宽系统权限。不具备 `/dev/net/tun` 的服务器需先由管理员或提供商启用设备，路由需自行配置。

不再使用 TUN 时，先停用全部 TUN 入站，再运行 `/usr/local/x-ui/x-ui tun disable` 撤销授权。

发行包提供 Linux amd64、arm64、s390x 及 SHA-256 校验文件，不发布 Docker 镜像。
