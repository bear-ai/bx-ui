# bx-ui 0.4.8

## 默认 root 运行

- 安装和管理脚本、面板、Xray 默认使用 root，不再创建独立的 x-ui 用户。
- 移除旧服务的能力、设备和文件系统限制，TUN 不再需要单独授权；服务器仍须提供 TUN 设备与所需内核权限。
- 安装目录及程序归 root:root，不向其他账户开放写权限；数据库、证书和私钥继续使用私密权限。
- 保留入站预检、启动失败回滚、在线更新校验等保护机制。
- 安装时清理未被修改的旧版 TUN 自动授权文件；自定义文件或符号链接会触发中止提示，不覆盖用户设置。

root 运行使系统权限更直接，也意味着面板被攻破会影响整个服务器。请保护登录凭据，并限制面板访问来源。

## 旧版迁移注意

页面在线更新仅替换程序，不会将现有非 root 服务提升为 root。首次迁移应以 root 执行项目 main 分支的新版安装脚本，或经 SHA-256 校验的 0.4.8 安装包内的 `install.sh`。不要使用旧版菜单的 `x-ui update` 代替首次迁移，它可能仍执行旧安装逻辑。

迁移保留账号、端口、入站和证书设置；历史 x-ui 用户不再使用，但不自动删除。完整安装会同时更新包内 Xray 核心，迁移过程需要重启服务。

旧 `tun enable` 命令改为仅检查当前进程权限，`tun disable` 仅显示面板停用指引；不再创建或切换授权覆盖文件。

发行包包含 Linux amd64、arm64、s390x 及 SHA-256 校验文件，Xray 兼容基线仍为 v26.3.27。
