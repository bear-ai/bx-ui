# bx-ui 0.4.9

## 密码规则与安装提示修复

- 面板账户密码最低长度从 12 个字符调整为 8 个字符，安装、重置密码及网页修改密码使用相同的后端规则。
- 安装和管理脚本在密码不足 8 个字符或超过 72 个 UTF-8 字节时明确提示原因，并要求重新输入；密码仍隐藏输入，不放入命令参数。
- 修复账户保存失败仍显示“设定完成”的问题。设置失败返回错误并中止后续流程，输入结束时安全取消。
- 修复登录页自动删除密码首尾空格导致无法登录的问题；密码中的空格、反斜杠和中文保持原样。
- 保留 bcrypt 加密成本 12、72 字节上限及已有密码兼容性，不自动修改现有密码。
- 新增密码边界、命令行退出状态、脚本重试与失败处理回归测试，并纳入发布前检查。

## 升级注意

页面在线更新只替换面板程序，新密码规则和登录修复会立即生效，但不会更新安装脚本或 `/usr/bin/x-ui` 管理脚本。因此旧管理脚本仍可能显示“至少 12 位”，也不会自动获得新的输入重试流程。

需要同步更新脚本时，请以 root 执行项目 main 分支的新版安装脚本，或经 SHA-256 校验的 0.4.9 安装包内的 `install.sh`。完整升级保留数据库中的账号、端口、入站和证书配置，并会重启服务、更新包内 Xray 核心。新版脚本使用新增的密码校验参数，不应与 0.4.8 及更早的面板程序混用。

发行包包含 Linux amd64、arm64、s390x 及 SHA-256 校验文件，默认 root 运行，Xray 兼容基线仍为 v26.3.27；不发布 Docker 镜像。
